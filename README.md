# game10003-cs-exercises
Various C# code exercise for Mohawk College's GAME 10003 Game Development Foundations course.

## Building

- `delete-all-temp.bat` runs a Python script that deletes `bin`, `obj`, and `.vs` folders.
- `update-all.bat` runs:
  - a custom CLI which updates the dotnet runtime version of all `.csproj`
  - a Python script that copies `./MohawkGame2D` into all subfolders named the same.
- `zip-all.bat` runs a Python script which makes a `.zip` of all (Solution) and (Challenge) subfolders.
